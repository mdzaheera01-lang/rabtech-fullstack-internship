# Accessibility Audit Report

## Website Audited

India.gov.in – National Portal of India

## Audit Tool

Google Chrome Lighthouse

## Accessibility Score

89

## Issues Identified

### WEB-001 – ARIA Parent Role Relationship

Lighthouse identified ARIA child roles that were not contained by their required parent elements.

### WEB-002 – Insufficient Color Contrast

Lighthouse identified background and foreground color combinations with insufficient contrast.

### WEB-003 – Incorrect List Structure

Lighthouse identified list items that were not contained within the required list parent elements.

### WEB-004 – Identical Links

Lighthouse identified repeated "Travel & Tourism" links in different locations.

### WEB-005 – Redundant Image Alternative Text

Lighthouse identified images whose alternative text may duplicate adjacent text.

## Evidence

Screenshots for each finding are stored in `docs/screenshots/`.

## Status

All five findings are documented as Open and require remediation review.
